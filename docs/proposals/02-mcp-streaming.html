设计要点（与现有代码的衔接）

  1. 现状约束：clients/client/src/main/mcp-host.ts 目前只处理 POST，GET / DELETE 返回 405；新增 SSE 端点须与既有无状态请求共存，不破坏 packages/mcp 的 12 个工具契约。
  2. 流式事件：定义 delta（文本增量）、progress（工具进度）、done / error 四类事件；AI 会话面板按事件更新对话与进度条（对应功能 01 的「正在调整…」状态）。
  3. 长任务分批：大型模板的 apply 拆成多批提交，每批独立做 revision 与封禁校验；任一批失败保留已完成批次并提供重试，避免整单回滚。
  4. Prompt / Resources：实现标准的 prompts/list|get 与 resources/list|read，把「生成单据模板」等指令与模板/字段/样例数据作为一等公民暴露给宿主 Agent；右下角「插入对话」直接把提示词填入功能 01 的输入框。
  5. 安全：SSE 沿用现有 Bearer pairing token 鉴权；资源读取仍需通过模板会话的 revision 校验，不绕过封禁元素规则。
被依赖：功能 01 的逐步进度与提示词快捷指令来自本功能；功能 03 的 SDK 需要把 SSE 作为一种可插拔传输。
