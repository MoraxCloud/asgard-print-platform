模板版本历史与可视化差异审阅

当前设计器没有版本时间线、差异对比与回滚能力，AI 变更与手动编辑混在一起无从追溯。本方案以内容 revision 为版本指纹保存快照，标注变更来源（手动 / AI / 导入），提供逐版本差异审阅与安全回滚。

设计要点（与现有代码的衔接）

  1. 版本指纹：直接复用 revisionOf()（键排序 + SHA-256）作为快照 ID；每次保存 / AI apply 后由画布重读新 revision，天然去重，内容相同不产生新版本。
  2. 来源标注：AI 变更来自 onApplyResult('success', …, revision)，手动保存来自设计器保存动作，导入来自模板导入流程；时间线用不同徽标区分。
  3. 差异计算：对相邻快照的元素树做递归对比，输出新增 / 删除 / 修改三类属性 diff；缩略图差异调用功能 04 的 /render/png 按 revision 出图。
  4. 安全回滚：回滚不是直接覆盖画布，而是把目标快照作为 template.apply 请求走同一通道——依旧先做 revision 一致性、封禁元素与结构校验，保证回滚也不会写入非法模板。
  5. 联动：AI 会话的每次变更自动进入时间线（功能 01），MCP 可暴露 history://list / history://get 资源供 Agent 查询（功能 02）。
独立价值 + 强联动：版本历史让 AI 变更可追溯，同时为所有模板操作提供安全网；建议与功能 01 同期规划数据结构，晚一步落地 UI。
