# 多语言配置与自定义

[← 返回目录](./README.md) | ← 上一篇：[jQuery / 原生 JS 接入](./05-jquery.md) | 下一篇：[插件安装与配置](./07-plugin-install.md) →

本文档描述 worm-print-platform 的完整多语言体系：**内置语言**（zh-CN / en-US / th-TH）与**外挂整语言包**（如 fr-FR）两条路径，覆盖内核引擎、命名空间与资源契约、宿主接入、插件、CLI、bundle 与三端加载。适用于设计器（`@worm-print-platform/canvas`）、同构渲染管线（`@worm-print-platform/core`）、渲染服务（render）与桌面客户端（client）。

## 3.1 目标与总体架构

- **一份 JSON 交付自定义语言**：宿主提供扁平点号键 JSON（键自带命名空间前缀，如 `constants.borderStyle.none`），无 `_meta`、无嵌套，即可让浏览器设计器、render 服务、桌面客户端显示完整自定义语言（帮助正文除外）。
- **一套引擎**：core 依赖 `i18next`，在其上做薄封装（`@worm-print-platform/core/i18n`）；各包只依赖 core 的 i18n 子路径，不直接接触 i18next。
- **五种命名空间，固定检索链**：`user` > 各插件 id > `constants` > `propertyTips` > `core`。core 拥有 `core`/`constants`/`propertyTips` 三个内置命名空间；插件拥有自身 ns。
- **内置三语零回归**：zh-CN 为源语言，en-US/th-TH 为完整译文；缺键一律回退 `zh-CN`，绝不显示裸 key 或空白。
- **资源真源单一**：中文文案只在资源 JSON 中存一份；core 常量改存语义键（`labelKey` / `tipKey`），不再有中文→译文映射表。

```
                  ┌──────────────────────────────────────────┐
                  │       @worm-print-platform/core/i18n      │
  t() / createTranslator(locale, messages?) / setLocale() ...
                  │       i18next 实例（薄封装 engine.ts）     │
                  └──────────────────┬───────────────────────┘
                                     │ resourceStore
   user（宿主/实例） → 插件 id → constants → propertyTips → core
   registerLocale /  el.messages   语义键资源（JSON 真源）
```

## 3.2 内核引擎

### 3.2.1 语言归一与探测

`normalizeLocale(input)` 规则（`i18n-instance.ts`）：

- 非字符串 / 空串 → `zh-CN`
- `/^en([-_]|$)/i` → `en-US`；`/^th([-_]|$)/i` → `th-TH`
- 其余（如 `fr-FR`、`ja-JP`）原样保留，靠缺键回退显示中文

`detectLocale()` 取 `navigator.language` 并归一，异常回退 `zh-CN`。未显式设 `lang` 的实例跟随全局 locale。

### 3.2.2 i18next 关键配置（不要随意改）

| 配置 | 值 | 原因 |
| --- | --- | --- |
| `keySeparator` | `false` | key 含点（`constants.borderStyle.none`），必须当扁平键 |
| `nsSeparator` | `false` | 不用 `ns:key` 前缀语法，命名空间靠 ns 数组检索 |
| `interpolation` | `{ prefix:'{', suffix:'}', escapeValue:false }` | 兼容 `{name}` 插值；文案含 HTML 不能被转义 |
| `fallbackLng` | `zh-CN` | 缺键与空串回退中文源文本 |
| `returnEmptyString` | `false` | `update` 写入的空值在运行时按缺失回退 |
| `defaultNS` | `core` | 内置核心资源所在命名空间 |

### 3.2.3 对外 API（`@worm-print-platform/core/i18n`，主入口亦 re-export）

- 状态：`setLocale(locale|null)`、`resetLocale()`、`getLocale()`、`subscribe(listener)`、`normalizeLocale(input)`
- 翻译：`t(key, params?)`、`translate(locale, key, params?)`、`createTranslator(locale, messages?)`
- 注入：`registerLocale(locale, messages)`、`mergeLocale(locale, partial)`、`registerPluginMessages(locale, pluginId, messages)`
- 诊断：`getMissingKeys()`、`clearLocales()`（只清 user 与插件层，不动内置三命名空间）、`getResources(locale?)`
- 类型：`Locale`、`Translate`、`LocaleMessages`、`CustomLocaleMessages`、`PluginLocaleMessages<Id>`
- 格式化：`formatNumber(value, locale, options)`、`formatDate(value, locale)`

插值用法：`t('toolbar.save')`；`t('diagnostic.position', { pos: 3 })` 对应文案 `位置 {pos}: ...`。

**`createTranslator(locale, messages?)` 与实例隔离**：不传 `messages` 时返回按全局引擎取词的 translator；传入时为该 `messages` 对象创建独立 i18next 实例（WeakMap 缓存），只承载 `user` 命名空间，**用户包命中优先，缺键/空串回退全局**。全局 `registerLocale` 语义不变，用于多实例共享一份包。`el.messages` 不再写全局，因此不会污染其他实例或全局 `t()`。

## 3.3 语言包组织与资源契约

```
packages/core/src/i18n/
  messages/                       core 消息 TS（诊断/校验/服务/外壳/表达式）
  locales/constants-{zh-CN,en-US,th-TH}.json    常量三语真源
  locales/propertyTips-{zh-CN,en-US,th-TH}.json 属性说明三语真源
  locale-keys.json               由 TS + JSON 合并派生的语义键清单
packages/core/dist/i18n/<locale>.json   构建后由 getResources() 生成（不手写）
marketplace/plugins/echarts/src/i18n/<locale>.json   插件语言资源（JSON 真源）
marketplace/plugins/echarts/dist/i18n/<locale>.json  构建产物
dist/i18n/resources.json         根 bundle 快照
```

包内声明（core 与 echarts 均已声明）：

```json
{ "wormPrint": { "id": "echarts", "i18n": { "dir": "dist/i18n", "base": "zh-CN" } } }
```

`dist/i18n/<locale>.json` 形状：顶层是命名空间，第二层是扁平键（键自带 ns 前缀），值为字符串：

```json
{ "echarts": { "echarts.panel.chart": "图表", "echarts.series.typeNames.bar": "柱状" } }
```

core 的文件含 `core`/`constants`/`propertyTips` 三个命名空间；插件文件只含自身命名空间。**插件必须提供 `zh-CN`，`en-US`/`th-TH` 可选**。插件命名空间 = `wormPrint.id`，必须与注册 `ElementUI` 时的 `i18nId` 一致。

**键三方对齐**：`npm run i18n:keys -w @worm-print-platform/core` 从 core 消息包与三语 JSON 合并派生 `locale-keys.json`；`npm run i18n:check` 校验 core / constants / propertyTips 三语键集合 parity。

## 3.4 宿主接入

### 3.4.1 浏览器：两种配方

**全局注入（多实例共享）**：

```ts
import { registerLocale, setLocale } from '@worm-print-platform/core/i18n'
registerLocale('fr-FR', frPack)   // 扁平点号键 JSON
setLocale('fr-FR')
```

**单实例隔离**：

```ts
const el = document.querySelector('print-designer')
el.lang = 'fr-FR'
el.messages = frPack             // 只作用于本实例，不写全局
```

`<print-designer>` 契约：`lang` attribute/property 为界面语言（缺省探测系统），`messages` property 仅对象，`setLocale(locale)` 运行时切换并立即重绘。Vue 3 门面提供同名 `lang`/`messages` props。

已知限制：未使用 `ctx.t` 的第三方插件 UI 仍跟随全局 locale。帮助弹窗正文与页签本期不做自定义语言（见 3.7）。

### 3.4.2 render 服务：环境变量

- `WORM_PRINT_LOCALE`：诊断语言，默认 `zh-CN`（en-* 走英文，其余中文）。
- `WORM_PRINT_LOCALE_FILE`：新增，扁平键 JSON 路径（绝对路径或相对进程 cwd）。启动时 `setLocale` 后读取并 `registerLocale`；文件缺失 / JSON 非法 / 值非字符串时 `console.warn` 并继续启动。

Docker 用法：`docker run -e WORM_PRINT_LOCALE=fr-FR -e WORM_PRINT_LOCALE_FILE=/app/locales/fr-FR.json -v $(pwd)/locales:/app/locales:ro ...`

### 3.4.3 桌面客户端：config.json + 内置兜底

`userData/config.json` 新增：

```json
{ "locale": "fr-FR", "localePack": "packs/fr-FR.json" }
```

`locale` 为空跟随系统；`localePack` 为空则回落应用 asar 内 `out/locales/<locale>.json`（随包发布）。`localePack` 为绝对路径或相对 userData 的路径。启动顺序：加载 config → `setLocale` → 加载语言包 → 初始化打印引擎；失败写日志 warn 并回退内置语言，不阻塞启动。新语言要么放进仓库根 `locales/` 后重新打包，要么填 `localePack` 后重启。

**统一发现约定**：显式配置（env / config.json / 浏览器宿主代码）优先；未配置时回落应用根 `locales/<locale>.json`。

## 3.5 插件多语言设置方案

### 3.5.1 契约：`ElementUI.i18nId` + `ElementUI.locales`

```ts
import { defineElementUI, registerElementUI } from '@worm-print-platform/plugin-kit'
import type { PluginLocaleMessages } from '@worm-print-platform/core/i18n'

const zh: PluginLocaleMessages<'myplugin'> = { 'myplugin.title': '我的插件' }
registerElementUI(defineElementUI({
  types: ['myElement'],
  renderCanvas: () => '',
  i18nId: 'myplugin',                       // 命名空间 id = 键前缀
  locales: { 'zh-CN': zh, 'en-US': en, 'th-TH': th },
}))
```

`registerElementUI()`（`plugin-kit/src/registry.ts`）对每个 locale 调 `registerPluginMessages(locale, pluginId, messages)`：前缀强校验（键必须以 `${i18nId}.` 开头）、按插件 id 注册命名空间并加入检索链、返回 dispose 句柄供注销清理。

### 3.5.2 插件包资源与发现

插件除 `ElementUI.locales` 外，还需声明 `wormPrint.i18n` 并产出 `dist/i18n/<locale>.json`（至少 zh-CN）。`@worm-print-platform/i18n` CLI 与市场 CLI 都据此发现资源。

**不要在模块加载期把译文求值成常量**：控件文本用 `ctx.t` 或 `t()`（渲染时取词）；导出常量存 key（如 `labelKey`），用 getter 取词。echarts 插件即采用此模式。

用户包可覆盖插件译文：`mergeLocale('en-US', { 'myplugin.title': 'Custom Title' })`。

### 3.5.3 图表插件语言包现状

`marketplace/plugins/echarts/src/i18n/{zh-CN,en-US,th-TH}.json` 各 149 键，涵盖 UI 文案、十类图表名称、标签预设/位置、notes 说明。键语义化（对齐 `echarts.series.typeNames.bar` 风格，无纯编号后缀）；构建脚本复制到 `dist/i18n/` 并同步兼容镜像 `packages/echarts/dist/`。

旧市场安装（`.worm-print/plugins.json` 中插件条目无 `i18n` 字段）没有语言资源，`worm-print-i18n` 会输出「插件 X 的语言资源未同步，请重新安装」提示，需重装插件副本。

## 3.6 常量与属性说明已迁入 i18next

纸张预设、边框线型、水印密度、内容标签与边框长提示现在都是语义键资源，中文文案只存 `constants-*.json`：

- `PAPER_PRESETS` 条目用 `labelKey`（如 `constants.paper.A4.label`）与 `group`（`common|dotMatrix|labels|receipt|continuous`）；分组显示键 `constants.paper.group.*`。
- `BORDER_LINE_STYLES` 用 `labelKey`（如 `constants.borderStyle.none`）；水印密度用 `constants.watermark.density.*`；提示用 `constants.hint.border.apply|pending|multi|mixed`。
- `PROPERTY_REGISTRY` 项用 `tipKey`（如 `propertyTips.ap-img-fit`，共 18 条）；`propertyTip(key)` 保留兼容导出，固定以 zh-CN 取词。
- canvas 已删除 `label-translation.ts` / `property-tip-translation.ts`，统一走 `tr(ctx, labelKey)` / `tr(ctx, tipKey)`。属性搜索分组标签与中文关键词只参与匹配、不显示，保持不变。

## 3.7 帮助弹窗（本期限制）

`help-content/` 按语言拆 `zh-CN/`、`en-US/`、`th-TH/` 三目录，各六章节。`getHelpSections(locale)` 按 locale 选择，`en-*`/`th-*` 走对应目录，**自定义语言（如 fr-FR）回退中文正文**。仅外壳标题与关闭按钮接入实例 translator（`HelpModalOptions.t`），跟随实例语言。帮助正文含 HTML 且用 `innerHTML` 渲染，本期不做多语言化、不引入 sanitize。

## 3.8 Bundle 导出（给用户拷到自己项目）

`npm run i18n:bundle`（前置 `npm run build`）运行 `scripts/export-locale-bundle.mjs`，从各包 `dist/i18n/*.json` 读取资源、帮助段继续从源码静态解析：

```
dist/i18n/resources.json   与   dist/i18n/resources.js   （export const resources）
结构：{ [locale]: { core, help, constants, propertyTips, echarts } }
```

`help` 是**静态内容快照，不参与运行时取词**。某插件 `dist/i18n` 缺失时打印 warn 并跳过，不报错退出。

```ts
import i18next from 'i18next'
import { resources } from './resources.js'
i18next.init({
  resources, lng: 'fr-FR', fallbackLng: 'zh-CN',
  keySeparator: false, nsSeparator: false,
  interpolation: { prefix: '{', suffix: '}', escapeValue: false },
})
```

## 3.9 两条工作流

### 内置语言开发 SOP

1. 新增语言：core `messages/` 加 `{locale}.ts`、`shell-*`/`expr-*`，键与 zh 一致；`constants-*.json` / `propertyTips-*.json` 加对应语言；插件 `locales` 加该语言（必须含 zh-CN）。
2. 帮助文档加 `help-content/{locale}/` 六章节并在 `index.ts` 加分支。
3. `npm run i18n:keys -w @worm-print-platform/core` 重生成键清单；`npm run i18n:check` 校验三语 parity；全量 `npm test`。

### 外挂语言包 SOP（自定义语言）

1. `worm-print-i18n template -o fr-FR.json`：导出扁平骨架（core → constants → propertyTips → 插件 id 字母序）。
2. 填写译文（保留 `{name}` 占位符、HTML 原样）。
3. `worm-print-i18n validate fr-FR.json --strict`：缺键/空值/占位符不一致/多键均报错，退出码 1。
4. 骨架更新后 `worm-print-i18n update fr-FR.json [--prune]`：保留已有译文、补新键为空串；随后再跑 `validate` 处理待翻译项（空值报错是预期）。

发现顺序：先读 `<项目根>/.worm-print/i18n/<id>/<locale>.json`（统一目录优先），再扫 `node_modules` 下声明 `wormPrint.i18n` 的包补充；`<项目根>` 默认 `process.cwd()`，CLI 的 `--dir` 可覆盖。退出码：0 成功 / 1 校验失败 / 2 用法错误。安装器支持 npx：`npx @worm-print-platform/i18n <命令>`。

## 3.10 校验与排查工具

- `npm run i18n:keys` / `npm run i18n:check -w @worm-print-platform/core`：生成/校验 `locale-keys.json`（含三语 parity）。
- `npm run i18n:bundle`：导出聚合资源；`npm run verify:i18n:full`：build + 全量 test + bundle + 一键校验。
- `node scripts/check-hardcoded-zh.mjs <dir...>`：扫描残留硬编码中文 UI 文案（跳过注释与语言包）。
- `getMissingKeys()`：开发模式缺键 `console.warn`，仅当 fallback 也缺才计入。
- 回归测试：`i18n-shell.spec.ts`、`messages-isolation.spec.ts`、`i18n-constants.spec.ts`、`help-i18n.spec.ts`、core 的 `namespaces.spec.ts` / `engine.spec.ts` / `bundle.spec.ts` / `locale-keys.spec.ts`。

## 3.11 保持不变的业务语义与已知限制

- **人民币大写**（`toUpperCaseAmount`）始终输出中文大写金额，不随 locale 变化。
- 打印 HTML 的 `<html lang>` 由 `GenerateOptions.documentLang` 控制（默认 `zh-CN`），**不随 UI 语言变化**——文档语言属于模板内容。
- 关系型数据整形工具 `reshapeRelationalData` 与多语言无关。
- 帮助弹窗正文中文（自定义语言回退）是已接受限制；后续可迁入 `help` 命名空间 + 译文白名单 + sanitize。
- 未使用 `ctx.t` 的第三方插件 UI 跟随全局 locale，不随实例语言变化。
