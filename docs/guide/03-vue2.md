# Vue 2.7 接入（Vue 2.7 Integration）

[← 返回目录](./README.md) | ← 上一篇：[Vue 3 接入](./02-vue3.md) | 下一篇：[React 18 接入](./04-react.md) →

> 目标：在 Vue 2.7 工程里用零框架主入口 `<print-designer>` 接出「设计器 → 预览 → 打印」。
> 可运行完整示例：`demos/apps/vue2`（9332，SFC + Options API）。
> Vue 2 走自定义元素：用 `registerAll()` 注册一次，字符串开关写 attribute，对象/函数赋 property，事件用 `@save` 绑定 CustomEvent。

## 1. 前置条件（Prerequisites）

- 已完成 [01](./01-getting-started.md)；一个 Vue 2.7 工程（runtime-only 构建即可，不需要 esm 编译版）。
- `npm install @worm-print-platform/canvas @worm-print-platform/core`，同号同批并锁文件；webpack 宿主同理，无打包器限制。
- 构建器需支持 Vue 2（Vite 用 `@vitejs/plugin-vue2`）。

## 2. 步骤（Steps）

### 2.1 一次性配置（`src/main.js`）

```js
import { registerAll } from '@worm-print-platform/canvas'
import Vue from 'vue'
import App from './App.vue'

registerAll() // 全局一次，注册 <print-designer>
Vue.config.ignoredElements = ['print-designer'] // 不声明会报 Unknown custom element、画面空壳
new Vue({ render: h => h(App) }).$mount('#app')
```

### 2.2 组件内挂载与注入（Options API）

```vue
<template>
  <div class="demo-app"> <!-- Vue 2 不支持多根 fragment，内容放单根节点内 -->
    <print-designer ref="designer" is-edit="true" show-help="true"></print-designer>
  </div>
</template>

<script>
import { createDefaultTemplate } from '@worm-print-platform/canvas'

export default {
  mounted() {
    const el = this.$refs.designer
    // 对象 / 数组 / 函数只能赋 property，写 attribute 会被字符串化
    el.fields = [
      { fieldKey: 'order.no', fieldLabel: '单号', fieldType: 'string', sortOrder: 1 },
      { fieldKey: 'goods', fieldLabel: '商品明细', fieldType: 'list', sortOrder: 2 },
    ]
    el.template = createDefaultTemplate() // 保存后回填时换成你的模板对象
    el.uploadImage = async file => this.uploadImage(file) // 返回可访问 URL
    // 事件也可用 addEventListener；用 @save 等 v-on 绑定 CustomEvent 同样生效
    el.addEventListener('save', this.onSave)
  },
  beforeDestroy() {
    this.$refs.designer?.removeEventListener('save', this.onSave)
  },
  methods: {
    onSave(e) {
      // detail 是模板 JSON 字符串；元信息由宿主分开存储
      const elements = JSON.parse(e.detail)
      // TODO: 提交到你的模板接口，例如 this.$api.putTemplate(elements)
    },
    async uploadImage(file) {
      // TODO: 换成你的上传接口，返回可访问 URL
      return URL.createObjectURL(file)
    },
  },
}
</script>

<style>
.demo-app print-designer { display: block; width: 100%; height: 100%; }
</style>
```

**样式**：`print-designer` 默认 `display:inline`，容器不给块级宽高会整体塌陷（见上方 CSS）。Shadow DOM 内联注入样式，普通用法无需引 CSS；只有 light DOM 形态才 `import '@worm-print-platform/canvas/style.css'`。

### 2.3 出纸（Printing）

**A 浏览器打印**（完整可运行写法）：

```js
import { renderHtmlPages, browserCodeRenderer } from '@worm-print-platform/core/browser'

const rendered = await renderHtmlPages(
  JSON.parse(el.getTemplateJson()), printData, location.origin, browserCodeRenderer)
const frame = document.getElementById('preview-frame') // 你的预览 iframe
const doc = frame.contentWindow.document
doc.open(); doc.write(rendered.html); doc.close()
frame.contentWindow.print()
```

**B 服务端 PDF / C 静默打印**：`PrintClient` 从 `@worm-print-platform/core/client` 导入，`printHtml(rendered)` 直送本机客户端（`127.0.0.1`，与浏览器同机）；PDF 走后端代理（见 01）。完整后端契约见技能 `references/server-render.md`、`references/silent-print.md`。

## 3. 验证（Verification）

```bash
npm run build   # 通过

```

## 4. 排错（Troubleshooting）

| 症状 | 原因 / 处理 |
| --- | --- |
| 设计器是空壳 / Unknown custom element | `main.js` 漏 `registerAll()` 或 `Vue.config.ignoredElements = ['print-designer']` |
| 传对象属性后画面异常 / `[object Object]` | 对象/函数（fields/template/fonts/uploadImage）只能赋 property，不能写 attribute |
| 读不到 fields | `fields` 没有 getter，读回看 `el.store.fields` |
| `structuredClone` 抛 `DataCloneError` | Vue 2 响应式 Proxy 不可结构化克隆；深拷贝用 `JSON.parse(JSON.stringify(...))` |
| 保存后未回填 | 用 `el.template = 新模板对象`（新引用），别复用旧引用；导出前先 `validateTemplate()` |
| 预览 iframe 拿不到节点 | `v-if` 控制的 iframe 要 `await this.$nextTick()` 再 `await requestAnimationFrame(...)` 两层后才拿得到 |
| 事件 detail 解析错 | `save`/`preview` 的 detail 是 JSON 字符串需 parse；`dblclick-element` 是元素 id 字符串、`dblclick-cell` 是 `{elementId,r,c,cellId}` 对象，都不要 parse |

## 5. AI 工具集成提示词（场景差异）

通用门控/安装/验收模板见 [01 §5](./01-getting-started.md#5-ai-提示词模板唯一模板源)，本场景额外约束：

```text
【宿主框架】Vue 2.7（SFC + Options API），构建器按项目现状。
- main.js 一次性 registerAll() + Vue.config.ignoredElements = ['print-designer']。
- 模板里只写字符串 attribute（is-edit="true" 等）；fields/template/uploadImage 等对象与函数
  在 mounted 后经 $refs 赋 property。
- 模板/数据深拷贝一律 JSON.parse(JSON.stringify(...))，不用 structuredClone。
- 事件用 addEventListener 或 @save 绑定 CustomEvent；beforeDestroy 里 removeEventListener。
- save/preview 的 detail 是 JSON 字符串；dblclick-* 的 detail 不要 parse。
【验收】构建通过；保存→回填→预览→浏览器打印链路跑通；不虚构 API（无 setTemplateMeta、back；fields 读回用 el.store.fields）。
```
