# 设计器国际化（i18n）

打印模板设计器（`@worm-print-platform/canvas`）与 core 渲染/诊断管线支持中文（默认）与英文切换，并允许宿主与插件注入自定义语言包。

## 语言与回退

- 内置语言：`zh-CN`（源文本）、`en-US`。`en-US` 是首版机翻草稿，未译键回退中文，后续可精修。
- 查词回退链（取第一个命中）：**用户自定义包 → 插件包 → 内置 en-US → 内置 zh-CN（源文本）**。缺键绝不显示键名或空白。
- 未指定语言时按 `navigator.language` 探测（`en-*` → `en-US`，其余语言标识如 `ja-JP` 原样保留；任一语言缺键时回退到内置中文源文本，因此非中英文 locale 实际渲染为中文，除非注册了对应语言包）；Node 环境（render 服务、client 主进程）显式设置，见下文。

## 宿主接入

`<print-designer>` 元素支持：

- `lang` attribute / `lang` property：界面语言（如 `en-US`）。
- `messages` property（仅对象，无 attribute）：自定义语言包，覆盖内置与插件译文。
- `setLocale(locale)` 方法：运行时切换并立即重绘。
- 未设 `lang` 的实例跟随 core 全局 locale；显式设置的实例不受全局变化影响。

```html
<print-designer lang="en-US"></print-designer>
<script>
  const el = document.querySelector('print-designer')
  el.messages = { 'toolbar.save': 'Store' }   // 覆盖个别文案
  el.setLocale('zh-CN')                        // 运行时切回中文
</script>
```

Vue 3 门面（`@worm-print-platform/canvas/vue3`）提供同名的 `lang` / `messages` props。

## 自定义语言文件

语言包是纯 TS/JSON 对象。键名清单见 `packages/core/src/i18n/locale-keys.json`（由 `npm run i18n:keys -w @worm-print-platform/core` 生成）。

```ts
// my-locale.ts
export const myZh = {
  'toolbar.save': '保存',
  'toolbar.preview': '预览',
}
```

宿主也可直接 `import` JSON 文件后赋给 `messages`（对象注入，不走 URL 异步加载）。

core 导出的类型：

- `LocaleMessages`：内置键的类型（键名补全）。
- `CustomLocaleMessages`：用户包类型，允许写任意键以覆盖插件译文。
- `registerLocale(locale, messages)` / `mergeLocale(locale, partial)`：注册用户语言包。
- `setLocale(locale)` / `getLocale()` / `subscribe(listener)`：全局 locale 状态。
- `t(key, params)` / `createTranslator(locale)`：翻译函数，支持 `{name}` 插值。
- `formatNumber(value, locale, options)` / `formatDate(value, locale)`：locale 感知格式化。

导入路径：`@worm-print-platform/core/i18n`（也从 `@worm-print-platform/core` 主入口 re-export）。

## 插件接入

插件在 `registerElementUI` 时声明 `i18nId` 与 `locales`，语言包按插件 id 前缀注册进引擎：

```ts
import { defineElementUI, registerElementUI } from '@worm-print-platform/plugin-kit'
import { t, type PluginLocaleMessages } from '@worm-print-platform/core/i18n'

const zh: PluginLocaleMessages<'myplugin'> = {
  'myplugin.title': '我的插件',
}
const en = { 'myplugin.title': 'My Plugin' }

registerElementUI(defineElementUI({
  types: ['myElement'],
  renderCanvas: () => '',
  i18nId: 'myplugin',
  locales: { 'zh-CN': zh, 'en-US': en },
}))
```

- 键必须以 `${i18nId}.` 开头，注册时校验，违规抛错。
- 用户包可覆盖插件译文：`mergeLocale('en-US', { 'myplugin.title': 'Custom' })`。
- 插件面板文案推荐用 core 全局 `t()`：插件 `locales` 已注册进引擎，`t('myplugin.*')` 按全局 locale 解析。`ElementUIPropertyContext.t` / `ElementUICanvasContext.t` 字段保留供宿主注入实例 translator，当前 canvas 未注入；多实例不同语言的插件面板跟随全局 locale。

## 帮助文档

`packages/canvas/src/shell/help-content/` 按语言拆为 `zh-CN/` 与 `en-US/`，`getHelpSections(locale)` 按 locale 选择；英文版为首版精简译文，后续可精修 `en-US/*.ts`。

## 服务端与桌面客户端

- render 服务启动时读 `WORM_PRINT_LOCALE`（默认 `zh-CN`）并 `setLocale`。
- 桌面客户端主进程用 Electron `app.getLocale()` 设置全局 locale。

## 保持不变的行为

- **人民币大写**（`toUpperCaseAmount`）始终输出中文大写金额，不受 locale 影响（业务语义）。
- 生成打印 HTML 的 `<html lang>` 由 `GenerateOptions.documentLang` 控制，默认 `zh-CN`，**不随 UI 语言变化**（文档语言属于模板内容）。

## 开发与校验

- `npm run i18n:keys -w @worm-print-platform/core`：生成键名清单。
- `npm run i18n:check -w @worm-print-platform/core`：校验清单与语言包一致。
- `node scripts/check-hardcoded-zh.mjs <dir...>`：扫描指定目录残留的硬编码中文 UI 文案（跳过注释与语言包）。
- 开发模式（非 production）缺键会 `console.warn`，便于排查。
