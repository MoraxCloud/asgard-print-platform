# 打印模板设计器国际化（i18n）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让设计器 UI、表达式编辑器、插件面板与运行时诊断全部支持中/英切换，并允许宿主与插件注入自定义语言包，默认中文行为逐字不变。

**Architecture:** core 新增无框架 i18n 引擎（globalThis Symbol 注册表 + 分层回退 + 订阅），以 `@worm-print-platform/core/i18n` 子路径导出；plugin-kit 在 `registerElementUI` 时把插件语言包按 id 前缀注册进引擎；canvas 通过 `ShellCtx.t` + `repaint()` 实现整树重渲染，Vue 门面与宿主契约同步暴露 `lang`/`messages`；诊断文案在 core 原地改为 `t()`。

**Tech Stack:** TypeScript 5.4/5.9（模板字面量类型）、Vitest + happy-dom、tsup、vite、npm workspaces。

**Spec:** `docs/superpowers/specs/2026-11-20-designer-i18n-design.md`

## Global Constraints

- 简体中文：回复、注释、提交信息、文档；标识符/包名/字段名保留英文。UTF-8 无 BOM，单次写入 ≤ 500 行。
- 不引入任何外部 i18n 依赖；core 保持纯逻辑、不依赖 UI 层；包边界不变。
- 默认 `zh-CN`：未配置时所有文案、诊断、格式化输出与改动前**逐字一致**。
- 查词回退链固定为：用户自定义包 → 插件包 → 内置 `en-US` → 内置 `zh-CN`（源文本）。缺键绝不显示键名或空白。
- 插件键强制 `${i18nId}.` 前缀；`i18nId` 缺省取 `ui.types[0]`，echarts 显式为 `'echarts'`。
- 宿主契约新增属性属 MINOR：`PRINT_DESIGNER_CONTRACT_VERSION` 由 `1.3.0` 升为 `1.4.0`。
- echarts 真源在 `marketplace/plugins/echarts`，`packages/echarts` 为 dist 镜像；改真源后必须跑 `npm run build -w @worm-print-platform/plugin-echarts` 触发 `sync-compat.mjs`。
- 不动 `worm-vue3-print` 仓库；canvas 为权威实现。
- 工作区已有未提交改动（`demos/apps/print-demo/**`、`package-lock.json`、`docs/superpowers/specs/2026-11-20-custom-function-validation-design.md`），本计划不触碰。

## Review Focus

1. 默认中文零回归：未传 lang 时所有已有中文断言必须保持通过 → Task 3/6/7/8 的 zh-CN 逐字断言。
2. 运行时切换不刷新数据：`setLocale()` 后整树重绘，但 store/选区/滚动位置不变 → Task 6 的 repaint 用例。
3. 插件语言包即时生效：注册/注销后应通知宿主并影响已挂载实例 → Task 5 的 `subscribe` 通知断言 + Task 9 的真源注册用例。
4. 用户覆盖插件译文：`mergeLocale('en-US', {'echarts.kind.bar': ...})` 必须压过插件包 → Task 1 分层用例 + Task 5 集成用例。
5. 中文残留漏网：shell/插件里仍有硬编码中文会破坏英文界面 → Task 2 的 `check-hardcoded-zh.mjs` + Task 7/9 的扫描步骤。
