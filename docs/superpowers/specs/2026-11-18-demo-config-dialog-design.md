# Demo 显示配置弹窗设计

日期：2026-11-18
状态：待确认（设计通过后进入计划）

> 需求变更：原「把顶部全部操作搬进弹窗」方案作废。新需求是**新增一个独立配置按钮**，
> 弹窗**不包含**任何现有顶部操作，只放设计器的显示配置。

## 背景与意图

四个宿主 demo 当前把 `:show-preview="true"` 等设计器入参写死在模板里，主题配色参数（`theme` / `themeConfig`）和保存按钮显隐尚未在 demo 暴露。需要在顶部增加一个配置入口，让使用者能在页面上直接切换这些显示项，便于演示刚落地的设计器参数能力。

## 目标

- 顶部新增一个「配置」按钮，位置在打印输出按钮附近、不占用原有操作。
- 点开一个弹窗，只包含三类配置：
  1. 预览按钮显隐（对应 `showPreview`）
  2. 保存按钮显隐（对应 `showSave`）
  3. 主题色配置（对应 `theme` + `themeConfig`）
- 现有顶部 7 类操作、三个弹窗、宿主切换与状态标识一律不动。

## 非目标

- 不搬运导出 / 导入 / 清空 / 加载示例 / 自定义字段 / 批量打印 / 打印输出到新弹窗。
- 不改动 `topbar-overflow.js` 的折叠链与现有顶部 DOM。
- 不改动设计器本体的接口或行为。

## 反目标

- 弹窗里塞入"其他暂时不需要"的配置项，导致范围膨胀。
- 把现有顶部按钮删掉或移位——本次只做加法。

## 弹窗内容（详细）

### 预览 / 保存按钮显隐

两个开关（checkbox），默认都开，与当前 demo 行为一致：

- 预览按钮：`showPreview`
- 保存按钮：`showSave`

开关变化即时写回 `<print-designer>` 的对应 property（Vue 用绑定，React 用 state，jQuery 用 `el.showPreview = ...`），无需重新加载模板。

### 主题色配置

- 预设三选一：跟随系统（`auto`，默认）/ 浅色（`light`）/ 深色（`dark`），对应 `theme`。
- 常用色覆盖：提供 4 个颜色输入，映射到 `themeConfig.overrides`：
  - 背景 `--pd-bg`
  - 表面 `--pd-surface`
  - 文字 `--pd-text`
  - 强调色 `--pd-accent`
- 每项留空表示不覆盖；提供「重置配色」按钮清空全部覆盖并回到 `auto`。
- 画布相关令牌（`--pd-paper` / `--pd-canvas-bg` 等）不在弹窗暴露，保持所见即所得。

## 约束

- 四个 demo 是独立 npm 工程，需分别实现，保持行为一致：vue3 / vue2 在 `App.vue`，react 在 `App.jsx`（建议新增独立 `ConfigDialog` 组件，与现有三个 Dialog 同风格），jquery 在 `index.html` + `src/app.js`。
- 设计器入参口径：字符串开关走 attribute，对象/函数走 property；`themeConfig` 是对象，必须走 property，`showPreview` / `showSave` / `theme` 可用 property 绑定。
- 新弹窗样式沿用各 demo 现有 `.demo-*` 命名与样式文件（`src/styles/demo-ui.css` 等），与已有三个弹窗视觉一致。

## 验收

- 四个 demo 顶部各多出一个「配置」按钮，原有顶部操作与三个弹窗照常可用。
- 配置弹窗只含预览显隐、保存显隐、主题色三组内容，切换即时生效。
- 主题预设与色值覆盖组合正确：传参优先于预设；重置后回到跟随系统且无覆盖。
- 保存 / 预览按钮隐藏后，`save()` 方法与 `save` / `preview` 事件仍照常可用（设计器既有语义）。
- 四个 demo 各手工点一遍，行为一致；既有测试通过。

## 留给 builder 的决定

- 配置弹窗各 demo 是独立组件还是内联（建议 react 独立组件，其余就近放在 App.vue / app.js）。
- 颜色输入用原生 `<input type="color">` 还是文本色值输入（建议原生颜色控件 + 清空按钮，避免非法色值）。
- 弹窗关闭方式沿用各 demo 现有弹窗口径（遮罩点击 / 关闭按钮）。
