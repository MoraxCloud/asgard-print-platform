# 采购订单模板重设计（A5 横向）

日期：2026-11-20

## 意图与原因

用户对当前「采购收货单」打印布局不满意。核心诉求：重新设计一份**采购订单**模板，要求**每一页**都显示供应商联系信息、收货人联系信息和订单号。

当前模板把这三块信息放在正文区的纯表头表格中，只在第一页出现；多页明细后续页缺少抬头上下文。

## 目标

- 供应商 / 收货人 / 订单号每页可见。
- 保留原有全部业务字段绑定：`order.no`、`supplier.*`、`receiver.*`、`goods.*`。
- A5 横向，沿用现有纸张以减少切换成本。
- 写回当前打开的设计器画布，可一次撤销回退。

## 非目标

- 不修改业务字段名、字段树或样例数据结构。
- 不改动桌面客户端、core 或其他包的代码。
- 不引入新依赖或插件元素。

## 约束

- 坐标 / 尺寸单位 mm；`fontSize`、`lineHeight`、`borderWidth` 单位 pt。
- 表达式写 `{字段}` 或 `{FUNC(字段)}`，不用 `${...}`。
- 聚合函数只用于表格 subtotal / summary 单元格。
- 表格列宽合计等于元素宽；data 行唯一，表头行 `repeatOnPage: true`。
- `html` 元素被封禁，不可使用。
- 页眉 / 页脚高度计入版心，需从内容高扣减。

## 方案（已选 A）

- **A（选中）**：三组信息全部放 `header` 页眉区，每页自动重复，坐标稳定，不参与正文分页结算。代价是页眉高度固定，需预留约 28mm。
- B：正文元素开 `repeatOnEveryPage`。首页 `top` 基准与续页归一规则不同，容易与明细表抢分页空间，放弃。
- C：页眉只放标题与订单号、联系信息放正文重复。关联信息被拆散，翻页需来回扫视，放弃。

## 设计

纸张 A5 横向（210×148mm），四边边距 10mm，页眉约 28mm，页脚 10mm，内容宽 190mm。

- **页眉（每页重复）**
  - 标题「采购订单」+ 订单号 `{order.no}`。
  - 供应商：`{supplier.name}`、`{supplier.phone}`、`{supplier.address}`。
  - 收货人：`{receiver.name}`、`{receiver.phone}`、`{receiver.address}`。
- **正文**
  - 商品明细表：列「商品名称 / 规格 / 数量 / 单价 / 备注」，表头行 `repeatOnPage: true`；设计高 32mm，行高 header 8 / data 8 / subtotal 7 / summary 7（mm）。
  - 小计行：数量 `{SUM(goods.qty)}`，备注留空。
  - 合计行：`{COUNT(goods.name)}`（项数）、`{SUM(goods.qty)}`（数量）、末格「客户签字：」。签字位并入合计行，避免独立跟随元素产生近空白尾页。
  - 商品名称绑定修正为 `{goods.name}`（原模板误写三连重复）。
- **页脚（每页重复，高 8mm）**
  - 页码 `{pageIndex}/{totalPages}`；移除原缺失图片的破图占位元素。

版式示意：

```
┌──────────────────────────────────────────────┐
│ 采购订单                订单号 {order.no}    │ ← 页眉（每页重复）
│ 供应商：{supplier.name}  电话：{supplier.phone}│
│         地址：{supplier.address}              │
│ 收货人：{receiver.name}  电话：{receiver.phone}│
├──────────────────────────────────────────────┤
│ 商品名称 │ 规格 │ 数量 │ 单价 │ 备注          │ ← 明细表（跨页重复表头）
│ … 数据行 …                                    │
│ 合计 {COUNT(goods.name)} │ {SUM(goods.qty)}   │
│ 客户签字：__________                          │
├──────────────────────────────────────────────┤
│                              1 / 3            │ ← 页脚（每页重复）
└──────────────────────────────────────────────┘
```

## 验收口径

1. `print_validate_template` 无 error。
2. `print_inspect_layout` 无 error（`LINE_OVER_CODE`、`OUT_OF_PAPER` 必须清零）。
3. `print_preview_template` 传足量样例 `printData`（表格展开多行），确认页眉信息完整、无遮挡、合计落位正确。
4. 写回画布后回读 `print_get_open_template` 确认内容生效。
