worm-print-platform · 打印设计器宿主示例总览

五个互相独立的示例工程。前四个演示各宿主接入打印设计器的全过程 —— 设计器挂载、模板与字段注入、宿主回调、事件、浏览器预览打印、服务端 PDF、客户端静默打印； print-demo 演示业务侧完整链路（模板管理 + 设计器 + 体检报告 + 静默打印配置，MSW 模拟后端）。 没有共用壳层，照抄其中一个工程即可落到你自己的项目里。 前四个页面的界面版式完全一致（各工程 src/styles/ 内的产物 CSS 保持同源）， 打开其中任意一个都能用顶栏的「宿主示例」下拉切到其余三个。

稳定版本：本仓 @worm-print-platform/canvas 已作为设计器权威实现正式发布（1.5.x 主线）， 是后续维护与迭代的主版本，可用于生产环境。旧仓 @worm-vue3-print/canvas（见 worm-vue3-print） 进入维护状态；Vue 3 老项目可经 /vue3 兼容门面零业务改动迁移。

Vue 3NPM 包接入

SFC 写法；编译期要配 isCustomElement。

cd demos/apps/vue3

业务接入示例NPM 包 + MSW

Vue 3 + Element Plus：模板管理 / 字段数据注册表 / 设计器 / 体检报告 / 静默打印配置，MSW 模拟 /sys/print/*。

cd demos/apps/print-demo
npm install
npm run dev   # :9336
打开 →
五个 demo 都能单独跑，本页由 node demos/scripts/serve-nav.mjs 挂在 :9300； npm run dev:demos:all 会顺带起它。 @worm-print-platform/canvas 是零框架 Web Component，设计器样式内置在组件 Shadow DOM； @worm-print-platform/core 提供同构出纸管线（renderHtmlPages / PrintClient）。 可选依赖：npm run dev:render（服务端 PDF，:3001）、本机 print-client 桌面客户端（:17521）； 两者不在时「打印输出」弹窗显示「离线」并给出可读提示。 验收：node demos/scripts/verify-demo.mjs http://localhost:<端口>/（前四个宿主同一套 34 项 UI 级断言；print-demo 用自身 28 项 vitest 单测验收）。
